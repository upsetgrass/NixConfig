# 我的 Neovim 提示

- `<leader>e`:  打开/关闭项目目录树
- `<leader>r`:  打开/关闭右侧文件大纲树
- `Ctrl-w w`:  切换目录、正文、大纲
- `<leader>f`:  fzf 查找项目文件
- `<leader>g`:  fzf 搜索项目文本
- `<leader>fc`:  切换 fzf 文件名匹配的大小写模式
- `<leader>tt`:  打开/关闭浮动终端
- 完整交互用 `:shell` 打开底部分屏，输入 `exit` 返回 Vim
- 项目目录树：`a` 新增文件/目录，`r` 重命名，`d` 或 `D` 移到回收站（不会永久删除）
- `<leader>h`:  打开/关闭本帮助

- (n)dd : 删除n行(并存储删除内容到"vim剪切板")
- .     : 重复上一条命令
- u     : 回退上一条指令
- (n)yy : 复制n行到vim剪切板
- (n)p  : 粘贴n次
